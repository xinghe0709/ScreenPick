# 屏选 ScreenPick

一个放在 Mac 菜单栏里的多屏截图小工具。

当 Mac 接了两块或更多屏幕时，直接按系统截图快捷键，常常会得到多张截图，还要回头找哪一张才是自己需要的。屏选会先把屏幕摆放位置显示出来，你点中哪一块，就只截哪一块。

## 它能做什么

- 显示当前连接的所有屏幕和它们的相对位置
- 选择一块屏幕后再截图，不容易截错
- 截图后可以复制、保存，或者两件事同时做
- 截图默认保存到“桌面/ScreenPick”文件夹
- 可选接管 `Shift-Command-3`，让这个快捷键也只截当前选中的屏幕

## 安装

目前需要从项目源码安装。你不需要先学会 Swift 或 Git，按顺序复制下面的命令就可以。每复制一行，按一次回车。

### 跟着做就行

#### 1. 打开“终端”

按下 `Command + 空格`，输入“终端”，然后按回车。你会看到一个可以输入文字的窗口。

#### 2. 安装电脑需要的工具

先在“终端”里复制下面这行命令，然后按回车：

```bash
xcode-select --install
```

如果弹出安装窗口，点击“安装”，等它完成。如果提示已经安装，直接进行下一步即可。

#### 3. 下载项目

下面的命令会把项目下载到 Mac 的“桌面”上。请一行一行复制到“终端”中，每输入一行按一次回车：

```bash
cd ~/Desktop
git clone https://github.com/xinghe0709/ScreenPick.git
cd ScreenPick
```

这三行命令分别表示：进入桌面、下载项目、进入刚下载的项目文件夹。`git clone` 就是“把项目下载到电脑上”。

如果看到 `git: command not found`，说明第二步还没有安装好。请先完成安装，再重新执行这三行命令。

如果看到 `already exists`，说明项目之前已经下载过了，不需要重复下载。继续执行：

```bash
cd ~/Desktop/ScreenPick
```

#### 4. 生成应用

确认自己仍然在“终端”里，并且刚才已经执行过 `cd ScreenPick`。然后运行：

```bash
./Scripts/build-app.sh
```

这一步会花一点时间。命令执行完成后，项目文件夹里的 `dist` 文件夹中会出现 `ScreenPick.app`。这是可以直接打开的 Mac 应用。

#### 5. 安装到 Mac

在“终端”中运行下面这行命令，打开生成应用所在的文件夹：

```bash
open dist
```

然后把里面的 `ScreenPick.app` 拖到 Finder 左侧的“应用程序”文件夹中，再双击打开它。这样以后就可以像打开其他 Mac 软件一样使用屏选了。

如果 macOS 提示无法确认开发者，可以在应用上点右键，选择“打开”，再选择“打开”。

#### 6. 第一次打开

屏选不会出现在 Dock 中，而是在屏幕右上角的菜单栏里显示图标。第一次使用还需要打开一些权限，具体看下面的[第一次打开要做什么](#第一次打开要做什么)。

以后想更新屏选时，打开“终端”，一行一行运行：

```bash
cd ~/Desktop/ScreenPick
git pull
./Scripts/build-app.sh
```

然后重新打开 `dist` 文件夹，把新的 `ScreenPick.app` 拖到“应用程序”中，替换旧版本即可。

## 第一次打开要做什么

### 给屏选截图权限

第一次截图前，macOS 会要求授权：

1. 打开“系统设置”。
2. 进入“隐私与安全性”。
3. 找到“屏幕与系统音频录制”。
4. 打开“屏选”的开关。
5. 退出屏选，再重新打开。

没有这个权限，屏选无法读取屏幕画面，也就不能截图。

### 如果想用系统截图快捷键

如果你打开了“接管系统全屏快捷键”，还需要在“隐私与安全性”中打开：

- “输入监控”里的“屏选”
- “辅助功能”里的“屏选”

如果你不使用这个功能，不需要打开这两项。

## 使用方法

1. 点击菜单栏右侧的屏选图标。
2. 在上方的屏幕布局图，或下方的屏幕列表中，点选目标屏幕。
3. 选择截图后要“复制”“保存”还是“两者”。
4. 点击蓝色的截图按钮。

如果已经打开“接管系统全屏快捷键”，选好屏幕后直接按 `Shift-Command-3` 也可以截图。按住 `Control` 再使用这个快捷键时，只会复制到剪贴板。

截图时，屏选菜单会自动收起，不会把自己的窗口截进去。保存的图片可以在“桌面/ScreenPick”中找到。

## 遇到问题怎么办

### 菜单栏看不到屏选

屏选没有 Dock 图标，请看屏幕右上角的菜单栏。如果还是看不到，可以重新双击“应用程序”里的 `ScreenPick.app`。

### 截图按钮不能点击

通常是还没有打开“屏幕与系统音频录制”权限。打开权限后，完全退出屏选，再重新打开。

### 打开权限后仍然不能截图

在“隐私与安全性”中关闭“屏选”权限，再重新打开一次，然后重启屏选。

如果使用系统快捷键，还要检查“输入监控”和“辅助功能”里的权限是否都已打开。

### 刚接上或拔掉一块屏幕

打开屏选后，点击右上角的刷新按钮，屏幕列表就会重新读取。
