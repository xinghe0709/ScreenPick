# 屏选 ScreenPick

一个放在 Mac 菜单栏里的多屏截图小工具。

当 Mac 接了两块或更多屏幕时，直接按系统截图快捷键，常常会得到多张截图，还要回头找哪一张才是自己需要的。屏选会先把屏幕摆放位置显示出来，你点中哪一块，就只截哪一块。

## 它能做什么

- 显示当前连接的所有屏幕和它们的相对位置
- 选择一块屏幕后再截图，不容易截错
- 截图后可以复制、保存，或者两件事同时做
- 截图默认保存到“桌面/ScreenPick”文件夹
- 可选接管 `Shift-Command-3`，让这个快捷键也只截当前选中的屏幕

## 安装

目前需要从项目源码安装。第一次安装按下面做就可以。

### 1. 准备电脑

- macOS 13 Ventura 或更新版本
- 一台 Mac

还需要安装 Apple 的命令行工具。如果电脑还没有，打开“终端”并输入：

```bash
xcode-select --install
```

如果弹出安装窗口，按提示完成安装即可。

### 2. 生成应用

打开“终端”，进入项目文件夹，然后运行：

```bash
./Scripts/build-app.sh
```

看到命令执行完成后，项目里的 `dist` 文件夹中会出现 `ScreenPick.app`。

### 3. 把应用放进“应用程序”

打开项目里的 `dist` 文件夹，把 `ScreenPick.app` 拖到 Finder 的“应用程序”文件夹中，然后双击打开。

如果 macOS 提示无法确认开发者，可以在应用上点右键，选择“打开”，再选择“打开”。

以后更新项目时，再运行一次 `./Scripts/build-app.sh`，然后用新生成的应用替换旧版本即可。

## 第一次打开要做什么

### 允许读取屏幕

第一次截图前，macOS 会要求授权：

1. 打开“系统设置”。
2. 进入“隐私与安全性”。
3. 找到“屏幕与系统音频录制”。
4. 打开“屏选”的开关。
5. 退出屏选，再重新打开。

没有这个权限，应用无法读取屏幕画面，也就不能截图。

### 如果要使用系统快捷键

如果你打开了“接管系统全屏快捷键”，还需要在“隐私与安全性”中打开：

- “输入监控”里的“屏选”
- “辅助功能”里的“屏选”

不使用这个功能时，不需要打开这两项。

## 使用方法

1. 点击菜单栏右侧的屏选图标。
2. 在上方的屏幕布局图，或下方的屏幕列表中，点选目标屏幕。
3. 选择截图后要“复制”“保存”还是“两者”。
4. 点击蓝色的截图按钮。

如果已经打开“接管系统全屏快捷键”，选好屏幕后直接按 `Shift-Command-3` 也可以截图。按住 `Control` 再使用这个快捷键时，只会复制到剪贴板。

截图时，屏选菜单会自动收起，不会把自己的窗口截进去。保存的图片可以在“桌面/ScreenPick”中找到。

## 常见问题

### 菜单栏看不到屏选

屏选没有 Dock 图标，请看屏幕右上角的菜单栏。如果还是看不到，可以重新双击“应用程序”里的 `ScreenPick.app`。

### 截图按钮不能点击

通常是还没有打开“屏幕与系统音频录制”权限。打开权限后，完全退出屏选，再重新打开。

### 打开权限后仍然不能截图

在“隐私与安全性”中关闭“屏选”权限，再重新打开一次，然后重启屏选。

如果使用系统快捷键，还要检查“输入监控”和“辅助功能”里的权限是否都已打开。

### 刚接上或拔掉一块屏幕

打开屏选后，点击右上角的刷新按钮，屏幕列表就会重新读取。
